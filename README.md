# Arthur Norgren - site pessoal mockup

Mockup estático inicial para validar estrutura editorial, hierarquia visual e uso da foto principal.

## Estrutura proposta

- **Home / abertura:** tese curta sobre IA aplicada em projetos reais.
- **Projetos:** busq.ai, Moob, second brain do MFO e outros casos vivos.
- **Notas de campo:** textos conceituais, relatos praticos e opinioes.
- **Sobre:** quem é Arthur e por que está escrevendo.

## Como abrir

Abra index.html no navegador.
